# イメージスキャンのために Trivy をインストールする

## 症状

Security ページがスキャナーの不在を報告する、またはイメージをスキャンしても何も
起きない。

## 原因

ColimaUI は脆弱性スキャナーを同梱していません。Trivy を呼び出す作りなので、
Trivy はホスト側にインストールされている必要があります。同梱しない理由はサイズ
です。Trivy の脆弱性データベースだけで約 1.2 GB あり、毎日更新されます。同梱は
古いコピーを配ることと同じです。

## 対処

macOS:

```bash
brew install trivy
```

Linux: お使いのディストリビューション向けの手順は
`https://trivy.dev/latest/getting-started/installation/` を参照してください。

確認:

```bash
trivy --version
```

その後 ColimaUI に戻り、Security ページを再読み込みします。

## 最初のスキャンはデータベースをダウンロードします

最初のスキャン（または数日ぶりのスキャン）では、まず脆弱性データベースを
ダウンロードします。この段階は進捗表示で分けて示されます。遅いのはこの部分で、
高速回線でおよそ 40 秒。その後 200 MB のイメージのスキャン自体は約 2.5 秒です。

データベースがディスクに置かれたあとは、ネットワークがなくてもスキャンできます。

## 何がどこへ送られるか

スキャンはローカルのコンテナランタイムからイメージを読みます。イメージ名、
パッケージ一覧、スキャン結果はすべて手元に残ります。外部への通信は Trivy が
自身の脆弱性データベースを取得するときだけです。

## 特定のイメージだけスキャンに失敗する場合

スキャナーが読めないイメージがあります。多くはレイヤーを展開できないケースです。
その失敗はそのイメージ限りで、他のイメージは通常どおりスキャンできます。
スキャナーのエラーテキストはそのまま表示されます。原因を知る手がかりがそれだけ
だからです。
