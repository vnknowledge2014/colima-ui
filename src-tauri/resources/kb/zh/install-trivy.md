# 安装 Trivy 以扫描镜像

## 现象

Security 页面提示缺少扫描器，或者点击扫描镜像后没有任何反应。

## 原因

ColimaUI 不内置漏洞扫描器，而是调用 Trivy，因此 Trivy 需要安装在你的主机上。
不内置的原因是体积：仅 Trivy 的漏洞数据库就约 1.2 GB，而且每天更新——内置等于
分发一份过期的副本。

## 解决

macOS：

```bash
brew install trivy
```

Linux：请按你所用发行版的说明操作，见
`https://trivy.dev/latest/getting-started/installation/`。

验证：

```bash
trivy --version
```

然后回到 ColimaUI，刷新 Security 页面。

## 第一次扫描会先下载数据库

第一次扫描（或隔了几天后的第一次）需要先下载漏洞数据库。这一步在进度显示中单独
呈现，因为慢的正是它——在较快的网络上约 40 秒，而之后扫描一个 200 MB 的镜像大约
只要 2.5 秒。

数据库落到磁盘后，扫描在没有网络时也能进行。

## 什么会被发送到哪里

扫描从本地容器运行时读取镜像。镜像名称、软件包清单和扫描结果都留在你的机器上。
唯一的外发请求是 Trivy 获取它自己的漏洞数据库。

## 当某个镜像扫描失败

有些镜像扫描器读不了，通常是某一层无法解包。该失败只属于那一个镜像，其余镜像照常
扫描。扫描器的错误文本会原样显示，因为那是判断原因的唯一线索。
